# data/ — 数据目录（数据库 + 附件）

> **这是你的数据，不是代码。备份 / 搬家只拷这一个文件夹。**

## 里面有什么

| 路径 | 说明 |
| --- | --- |
| `linkoa.db` | **数据库**（SQLite 单文件），全部业务数据（项目 / 客户 / 用户 / 流程 / AI 对话等） |
| `uploads/` | 上传的附件（按日期分子目录：`cover/` 封面、`node_icon/` 节点图标、`node_form/` 节点表单图、`YYYYMMDD/` 附件） |
| `.gitkeep` | 占位文件，保证空目录能入库（其余内容被 `.gitignore` 忽略，**不会上传 GitHub**） |

## 使用说明

- **本地启动（start.bat / start.sh / 手动）与 Docker 容器共用这一份数据**（V1.4.18 起统一）。
- 首次启动自动创建空库 + 初始管理员 `admin / admin123`；想恢复干净演示环境，删掉 `linkoa.db` 重启即可自动重建。
- **备份**：把整个 `data/` 文件夹拷走即可。
- **迁移到新机器**：拷走 `data/` → 新机器启动后数据原样可用。
- ⚠️ 删除 / 清空前先确认不是需要的业务数据。
